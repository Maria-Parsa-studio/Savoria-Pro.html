# 🍷 Savoria — Fine Dining Restaurant Landing Page

Elegant, warm landing page for a Mediterranean fine-dining restaurant with menu, chef story, gallery and table reservation.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![Responsive](https://img.shields.io/badge/Responsive-Yes-c0392b)

## ✨ Features

- Topbar promo + sticky navbar
- Cinematic hero with Michelin badge
- Stats strip (rating, chef years, dishes, rooftop)
- Signature menu grid with prices & category tabs
- Chef story section
- Photo gallery (interior, terrace, cellar)
- Guest reviews
- Reservation form (date, time, guests)

## 🛠️ Tech Stack

- Pure HTML5 + CSS3
- Google Fonts: Playfair Display + Inter
- Images: Unsplash CDN

## 📁 Structure

```
savoria-restaurant/
├── index.html
└── README.md
```

## 🚀 Run Locally

Just open `index.html` in a browser.

## 🌐 Deploy on GitHub Pages

1. Create repo `savoria-restaurant`
2. Upload files, Settings → Pages → `main` → `/ (root)`
3. Live at `username.github.io/savoria-restaurant`
